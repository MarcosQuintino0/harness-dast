Espaço, forma e tamanho de tela

Poucas medidas, sempre as mesmas. Não há sombra: o que separa as coisas é o tom do fundo e uma linha de 1 px.

Como a tela se adapta

Não há pontos de quebra fixos. Os painéis ficam lado a lado enquanto couberem e descem para a linha de baixo quando não cabem (flex-wrap). Cada painel declara a largura mínima que aceita.
