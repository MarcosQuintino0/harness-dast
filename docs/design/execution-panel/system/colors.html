As 4 cores que querem dizer algo

Verde: feito, passou, corrigida.
Azul: acontecendo agora, e tudo que é clicável.
Vermelho: falha grave ou erro. Não usar para enfeite.
Amarelo: atenção: a confirmar, parcial, não testado.

Regras

Cor nunca vem sozinha: todo estado tem também uma forma ou uma palavra.
Texto sempre com contraste de 4,5:1 ou mais. Todos os pares acima passam.
Cor "soft" só como fundo da cor forte do mesmo nome.
Sem degradê, sem sombra, sem brilho. A profundidade vem dos 3 tons de fundo.
Gráfico de quantidade (tempo, tokens, pedidos barrados) usa branco e cinza. As 4 cores ficam só para estado.

Nomes no desenho e no código

Nos arquivos deste canvas as variáveis têm nome curto. No código, usar o nome longo da tabela.

--bg → --color-bg
--s1 → --color-surface
--s2 → --color-surface-2
--ink → --color-text
--mu → --color-text-muted
--ln → --color-border
--run → --color-live
--ok / --gr / --am → --color-ok / danger / warn
